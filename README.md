# Новый образ

Учебный сайт студии красоты для практического занятия №9 по фронтенд и бэкенд разработке. Проект выполнен отдельно от контрольных работ интернет-магазина.

## Что есть на сайте

- адаптивная главная страница с Bootstrap-сеткой;
- навигация с мобильным меню;
- услуги, сетка популярных услуг, пример команды мастеров и учебный прайс;
- галерея идей причёсок;
- демонстрационная форма выбора услуги, мастера, даты и времени.

Имена мастеров и цены придуманы для учебного проекта. Изображения созданы генератором изображений и иллюстрируют идеи причёсок; они не являются фотографиями работ реальной студии. Форма не бронирует время и не отправляет персональные данные: она только показывает выбранный вариант в браузере.

## Практическая работа №9

Bootstrap 5.3.3 подключён через CDN, затем подключён `css/custom.css`; Bootstrap JS Bundle подключён перед закрывающим тегом `body`. Страница использует `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*`, `offset-*`, а также utility-классы для отступов и выравнивания. Сетка популярных услуг использует `col-12 col-md-6 col-lg-4`: одна колонка на телефоне, две на среднем экране и три на широком. Hero-блок, раздел преимуществ, блок услуг и галерея тоже перестраиваются на узких экранах. Собственные стили отвечают за визуальный образ студии.
